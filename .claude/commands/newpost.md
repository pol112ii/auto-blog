# /newpost

키워드 하나를 받아 원고를 쓰고, 블로그스팟에 발행하고,
네이버에 임시저장까지 한다. 네이버 발행 버튼은 누르지 않는다.

원고는 네가 직접 쓴다. 파이썬 코드 안에서 어떤 유료 API 도 부르지 않는다.

## 0. 키워드 정하기

인자로 받은 키워드: `$1`

- `$1` 이 있으면 그걸 쓴다.
- 비어 있으면 `python pipeline.py next` 로 고른다.
  (keywords.csv 에서 status 가 빈 첫 줄. 이미 처리된 키워드는 나오지 않는다)

작업 폴더를 만든다. 출력된 경로를 이후 단계에서 계속 쓴다.

```
python pipeline.py init "<키워드>"
```

이미 처리된 키워드면 여기서 멈춘다. 사용자에게 알리고 끝낸다.

## 1. 원고 작성

`prompts/post_generator.md` 를 **그대로** 읽고 그 지시를 따른다.
요약하거나 고쳐 쓰지 않는다. 치환하는 값은 다음 다섯 개뿐이다.

| 자리표시자 | 값 |
|---|---|
| `{{KEYWORD}}` | 키워드 |
| `{{OFFICIAL_URL}}` | `meta.json` 의 official_url |
| `{{EXTRA_URLS}}` | `meta.json` 의 extra_urls (비었으면 해당 버튼을 생략) |
| `{{GOOGLE_URL}}` | **지금은 그대로 둔다.** 2단계에서 실제 주소로 바뀐다 |
| `{{TODAY}}` | `meta.json` 의 today |

결과를 작업 폴더에 저장한다.

- `B.html` — [B] 블로그스팟용 (자리표시자가 하나도 남으면 안 된다)
- `A.html` — [A] 네이버용 (`{{GOOGLE_URL}}` 만 남아 있어야 한다)
- `NAVER_TAGS.txt` — NAVER_TAGS 를 쉼표로 이어서 한 줄
- `IMAGE_CARDS.txt` — 소제목 3개를 한 줄에 하나씩
- `meta.json` 의 `title` 에 생성한 공통 제목을 적는다

확인할 것:

- [A] 와 [B] 의 제목이 같은가
- [A] 에 표·전체 절차·FAQ 가 들어가지 않았는가
- [A] 와 [B] 의 문장이 겹치지 않는가 (겹치면 [A] 를 다시 쓴다)
- 입력값에 없는 URL 을 지어내지 않았는가

## 2. 블로그스팟 발행

```
python pipeline.py publish <폴더>
```

`B.html` 의 모든 링크를 검사한 뒤 발행하고,
받은 주소를 `A.html` 의 `{{GOOGLE_URL}}` 에 넣는다.

링크 검사에 걸리면 발행되지 않는다. 그때는 지어낸 주소나
`[URL_확인필요]` 를 사람에게 알리고 멈춘다. 임의로 고치지 않는다.

## 3. 소제목 카드 이미지

```
python pipeline.py cards <폴더>
```

## 4. 네이버 임시저장

```
python pipeline.py naver <폴더>
```

네이버 블로그가 여러 개다. 어디에 저장할지는 이 순서로 정해진다.

1. 사용자가 `$2` 로 아이디를 줬으면 `--blog-id <아이디>` 를 붙인다
2. keywords.csv 그 줄의 `naver_blog_id`
3. `.env` 의 `NAVER_BLOG_ID`

어느 블로그에 저장했는지 마지막 보고에 반드시 적는다.

크롬 창이 뜬다. 크롬이 이미 켜져 있으면 프로필이 잠겨 실패한다.
그때는 크롬을 닫고 이 단계만 다시 돌리라고 알린다.

## 5. 기록

```
python pipeline.py done <폴더>
```

## 마지막에 보고할 것

- 블로그스팟 주소
- 네이버 임시저장 여부 (발행하지 않았음을 분명히 밝힌다)
- 어느 네이버 블로그에 저장했는지
- 작업 폴더 경로

## 실패했을 때

각 단계는 결과를 파일로 남기고 이미 끝난 일은 건너뛴다.
`python pipeline.py status <폴더>` 로 어디까지 됐는지 보고,
실패한 단계부터 다시 돌린다. 처음부터 다시 하지 않는다.
